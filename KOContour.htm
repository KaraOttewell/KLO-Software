KOContour

Contour map display for elevation data files or DEM elevation servers such as Open Topo Data and OpenTopography — and not only for the Earth: it can also map the Moon, Mercury, Venus, Mars, Vesta, Ceres, Pluto and Charon.

Windows UWP Microsoft Store Free

Overview

KOContour draws contour maps — and 3D relief views — showing the height of the ground. It can download the heights for any area you choose, anywhere on the Earth (see Use a DEM Server) or on the Moon, Mars and other worlds (see Maps of Other Worlds), or open a data file you already have (see Load Data). The sections below have screenshots showing how the main features work.

If you make your own data files: the file format

KOContour reads elevation data files from your computer and displays them as contour maps. A typical data file would look like this: 

type  latitude        longitude       altitude (ft)  name         desc
T     53.231479474    -6.299506408    1672.9         Stillorgan   Ireland
T     53.231479474    -6.299119017    1678.8
T     53.231479474    -6.298731626    1687.9
T     53.231479474    -6.298344235    1698.1
T     53.231479474    -6.297956845    1704.0
T     53.231479474    -6.297569454    1708.2
T     53.231479474    -6.297182063    1709.2

The example above assumes tab-separated columns, which is recommended so that your description field can then use commas.

Data files that KOContour creates for you have one more column at the end, headed body, which names the world the data is of — Earth, Moon, Mars, Pluto and so on — on the first data line only, like the name and description. You do not need to add it to your own files: a file without a body column is taken to be of the Earth. See Maps of Other Worlds.

The most up to date version of this information will always be the online version.

Creating the Input Data Files

Use a DEM Server (recommended for most people)

There are a number of Digital Elevation Model (DEM) servers on the internet, and KOContour can fetch your elevation grid directly from two of them — no external website needed. These are built in, choose one from the DEM server suggestions which will pop up if you type open into the DEM server URL field.

  • Open Topo Data https://api.opentopodata.org/ — needs no key. It limits you to 100 locations per call at one-second intervals and 100,000 points per day, so a large grid can be a little slow. You can also host this server yourself to remove those limits.
  • OpenTopography https://portal.opentopography.org/ — fetches the whole region in a single call, so it is much faster for large or dense grids and offers more datasets (including 10 m USGS 3DEP for the USA). It needs a free API key: register on its site, then click the padlock button which appears beside the server box when the opentopography.org server is chosen, and paste in your key (tip: right-click that padlock to copy the “get a key” web address). KOContour picks the best dataset for your selected country automatically — COP30 worldwide, USGS 10 m for the US.

You should type the URL of your chosen server in the DEM server box. KOContour knows how to “talk” to these, and any others which use the same protocol, such as if you run your own in a Docker environment.

These two servers hold data for the Earth. To get elevation data for the Moon, Mars or another world, set the Planet/Body drop-down at the top of the same dialog instead: the right server is then chosen for you and no key is needed. See Maps of Other Worlds.

Open Topo Data — https://api.opentopodata.org/
OpenTopography — https://portal.opentopography.org/

The trailing /API is optional — KOContour accepts either form. Both are also already in the server dropdown, so you can just select one.

As well as the public Open Topo Data server (api.opentopodata.org), KOContour can use any self-hosted Open Topo Data server (it is open-source, and meant to be run on your own computer or server) — or indeed any other elevation server that works the same way.

For those who like technical details (you don’t need any of this to use KOContour)

The “Open Topo Data API” implements a custom REST API: GET/POST /v1/{dataset}?locations=lat,lon|lat,lon → JSON {results:[{elevation, location}]}. There is no formal standard name; it was deliberately modelled to look similar to the Google Maps Elevation API. It is one of a family of “elevation point-query” JSON APIs, but they are not drop-in compatible with one another.

The “OpenTopography API” implements custom REST endpoints (globaldem?demtype=…, usgsdem?datasetName=…) that return a raster file for a bounding box. You will need to request an API key to use this, but it is free.

The real standard for “give me a DEM raster for this bounding box” is OGC WCS (Web Coverage Service) — with its cousins WMS / WMTS for map images. Many DEM servers expose WCS (national mapping agencies, GeoServer / MapServer / THREDDS instances, and so on). OpenTopography's API plays the same role as WCS but is not WCS — it is its own thing.

When you have chosen your server, make sure you enter the API key using the padlock button in the lower right of the dialog. The grid resolution dropdown below the dataset name will be populated with suitable values (you may have to “tab off” the server name field), so select the one you want. Similarly a dataset recommendation will be selected, but you can override that if you wish. Once you are done setting up your selection parameters click Generate TSV from DEM server; a file picker lets you choose where to save the data — I recommend making a ContourMaps folder under your Pictures folder and use file type .tsv which is just tab-separated values. KOContour is registered as a handler for .tsv files so you can just double-click on them to open a map if you use that. Click the Save button and the download will begin.

While the elevations download, a small map of the area pops up with the area being downloaded outlined in red — here the country around Stonehenge and Amesbury, on Salisbury Plain — so you can check at a glance that it is the place you meant. Drag it by its title bar to move it, and use its + and − buttons to zoom out for a wider view. It is a map of the Earth from OpenStreetMap, so it appears only for Earth downloads, and it closes by itself when the download finishes.

You will also see a progress information popup, which you can hide by clicking the Close and keep going button (click on the main toolbar button to see it again), and you can cancel the operation if, for example, you are warned that the dataset you chose does not have elevations for the points you requested. (The dataset KOContour picks for your country — see Which dataset? above — should avoid that.) For the opentopodata.org server it is possible to display the actual progress percentage, but for opentopography.org an “indeterminate” (busy) progress bar has to be used. When the download is complete, KOContour closes the progress box and loads the new map for you, as long as Load the map as soon as the download finishes is ticked at the bottom of the dialog (it is to begin with, and the app remembers your choice). With it unticked, close the progress box yourself and use the Load Data button to load the file you created.

Saving Map Service Keys or Usernames

You can register for various free map services with DEM servers, or GeoNames which, for individual, low-use, are likely more than adequate in the speed and number of daily transactions.

Once you have your account and username or key, click on the padlock button, and paste the appropriate one into the popup dialog. Click Save to save it in KOContour’s own settings on this PC. You are now ready to download data from the map service or elevation data for individual places from GeoNames. Not sure how to get a username or key? The Help me get… link under the box opens this page at the steps for that service, and leaves the box open so you can paste in what you get.

Which dataset? KOContour picks the best one for the country you have chosen, so you can usually leave it as it is. With Open Topo Data that is eudem25m across Europe, including the UK, ned10m in the USA, nzdem8m in New Zealand and mapzen everywhere else — and where one of the first three has no data, such as over the sea, KOContour fills the gap from mapzen, so a coastal map comes out complete. With OpenTopography it is USGS10m in the USA and COP30 everywhere else. For a very large area, use a coarser 90 m dataset (such as COP90 on OpenTopography) or make the area smaller.

Maps of Other Worlds

KOContour is not limited to the Earth. The Planet/Body drop-down at the very top of the Download data from DEM server dialog chooses which world the elevation data is for. It starts on Earth, and also offers the Moon, Mercury, Venus, Mars, the asteroid Vesta, the dwarf planets Ceres and Pluto, and Pluto's moon Charon. Choose one of those and the rest of the dialog adjusts itself:

  • The DEM server becomes the USGS Astrogeology server (https://planetarymaps.usgs.gov/), which publishes the elevation models of all these worlds. It is the only source for them, so the server box simply shows it and cannot be changed. It needs no key, so the padlock button is hidden.
  • The dataset drop-down holds the single elevation dataset for that body (see the table below).
  • The grid resolution drop-down offers the full range of grid sizes, up to 840×472 points.
  • Extent Units switches to Degrees, the unit the suggested maps on this page are given in (going back to the Earth restores the units you had before). You can still choose miles or kilometres if you prefer.
  • The place-name search in the Title field looks through KOContour's built-in places for that world: type olym on Mars and choose Olympus Mons, and the title, description and centre coordinates are filled in for you (choose the extent yourself). Anywhere else, type your own title and coordinates.
  • The things that only exist for the Earth are switched off: the Country selector, the GeoNames button and the Create GPX file option.

You describe the area exactly as you do for the Earth: a centre latitude and longitude, and a horizontal extent in whichever units you like. A few things are worth knowing:

  • Longitudes run from −180 to 180, with east positive, as on the Earth. Maps of other worlds often quote longitudes from 0 to 360 east; subtract 360 from anything over 180. Olympus Mons on Mars, at 226.2°E, is entered as -133.8.
  • The same distance covers more degrees on a smaller world. KOContour allows for this: with the extent given in kilometres or miles, the Degrees figure shown beneath it is worked out for the body you have chosen. 100 km is about 0.9° of longitude at the Earth's equator, 1.7° at Mars's, 3.3° at the Moon's — and about 22° on little Vesta.
  • On Pluto and Charon, only half of the world has data (see the table). If some points of your area have no data, KOContour warns you before saving, and those parts of the map are left blank: the contour lines stop at the edge of the data, the shaded and 3D views leave the area empty, and the status text says how many points have no data. Keep the area inside the covered half to fill the whole map.

Behind the scenes the elevations arrive in two different ways, and KOContour handles both for you. For the Moon, Mercury and Mars, the USGS map service cuts out just your area and sends it in one go (it wants the area in degrees for the Moon and in metres on the body's own map grid for Mercury and Mars; KOContour converts for you). The other worlds' elevation models are single whole-world files of between 64 MB and 591 MB, so KOContour reads only the parts of the file your area needs — typically from a few hundred kilobytes to a few megabytes, depending on the size of the area and the number of grid points. The progress popup shows how much is being downloaded, and you are asked first if it would be more than 100 MB.

What is different about a map of another world

A data file remembers which body it is of (see the body column in the file format notes in the Overview), so once a file of another world is loaded everything is worked out for that body:

  • The status text names the body, and says what its elevations are measured from.
  • Distances are right for that world. The distance scale, the extent shown in the status text and the distance and bearing tool all use that body's own mean radius — for example 1737.4 km for the Moon, 3389.5 km for Mars and 262.7 km for Vesta — rather than the Earth's.
  • The height key means something slightly different. On the Earth the heights in the key on the left of the map are heights above sea level. No other world here has a sea, so their heights are measured from an agreed reference surface — usually a perfect sphere (the table above gives its radius for each body), and for Mars the areoid. Zero is therefore just the height of that reference surface, not a shoreline, and negative heights are perfectly normal — much of the Moon's near side and most of Mars's northern hemisphere lie below zero. A crater floor at −3,500 m is 3,500 m below the reference surface, not below any water. On Vesta and Ceres, which are not round, the heights also carry the body's overall shape, so over a large area they include a broad slope as well as the craters and hills.
  • Colour schemes that suggest water should be read with that in mind. The Terrain + water scheme colours everything at or below zero blue, and the Hue Ramp starts with a blue “sea level”. On other worlds those blues simply mark ground below the reference surface. Hypsometric, Greyscale and Viridis carry no such suggestion and often suit these maps better.
  • Heights in the data file are in metres, as they are for Earth data downloaded from a DEM server.
  • Places belong to a body too, so only places you have added for that body appear on the map, and place names cannot be looked up automatically — see Places on other worlds.

Create elevation data for an area

KOContour draws its contours from a regular rectangular grid of elevation readings: the contouring algorithm needs evenly-spaced points laid out in rows and columns, not a scattering of random measurements. The Create data dialog (the same button described above) builds exactly such a grid for the area you specify — a centre latitude/longitude and a horizontal extent — and, with the DEM service option, looks up the elevation of every grid point for you and saves a ready-to-load .tsv file in one step. No external website is involved.

(The dialog also has a Create GPX file option that writes just the grid of latitude/longitude points with no elevations, in case you want to fill them in with a separate elevation tool of your own. Most people will simply use the DEM-server route above, which does the elevation lookup directly.)

Alternatively, here is a folder of ready-made data files to download — tab-separated files ready to load, including Maui and examples from the Moon, Mars and Pluto. As always, do a virus scan just as you would for any file you download.

Example: Create data for Maui

Find the centre of your area in your favourite map source, e.g. Google Maps: search for Maui, right-click the chosen spot, and left-click the coordinates that pop up to copy them to the clipboard — something like 20.800841, -156.327220. Then click the Create data button to open the dialog.

Click the field labelled Paste lat,lon here and paste the coordinates; the Latitude and Longitude fields fill in and stay in sync (you can also type them individually). As a quick alternative, type a place name into the Title field and choose an entry from the drop-down of suggestions that appears — selecting one fills in the coordinates for you; use the country selector beside the Title to restrict the search to a particular country. Fill in the other fields until they all show a green border, indicating they are valid.

Select the DEM service option and choose a server — Open Topo Data (no key needed) or OpenTopography (once you have pasted in its key). Pick a dataset and a grid resolution, then click Generate TSV from DEM server and save the file as Maui.tsv in your data folder. A progress popup shows while the elevations are fetched; when it finishes, your new map is loaded and drawn straight away (or, if you have unticked Load the map as soon as the download finishes, close the popup and use Load Data).

Loading the Input Data Files

Click the highlighted button, which will show a standard file picker letting you select one of the input files you created above. A contour map will be generated from the data and should look similar to the picture below.

Contour map of Maui generated from the downloaded elevation data

When you load a data file it is added to the Show Favourites list dialog, and you can double-click on entries there to load the data again. Entries are sorted with the most recently loaded at the top. Superimposed on the map you can see the zoom and pan controls, along with the height scale on the left and the distance scale in the lower right.

To zoom into a particular area, click and drag a rectangle across the map. A white selection box — matching the proportions of the map window — follows the pointer as you drag, and releasing the mouse button zooms to the selected area. Press Esc while dragging to cancel without zooming. The zoom and pan buttons in the lower-right corner give step-by-step control.

On a touchscreen you can also use two-finger gestures on the map: pinch two fingers together or spread them apart to zoom out or in — the zoom is centred on the point midway between your fingers — and drag with two fingers to pan the map, which follows your fingers and stops at the edges of the loaded data so you cannot scroll off into empty space. Pinching and panning can be done together in one gesture. A mouse wheel (or precision-touchpad pinch) also zooms.

Choosing How the Contours are Drawn

The drop-down near the top of the window selects how the loaded data is drawn. There are four modes:

  • Lines — the classic contour map, each level drawn as a coloured line.
  • Gradient Shade — the map is filled with a smooth colour gradient that blends from one contour level to the next.
  • Block shade — each contour band is filled with a single solid colour, giving a stepped, "layer-cake" look.
  • 3D — the terrain is drawn as a shaded three-dimensional relief surface that you can rotate and zoom (see The 3D Relief View below).

The colours used by every mode are set by the colour scheme, and the number of bands by the contour-levels slider, both described below.

Adjusting the Number of Contour Levels

The slider near the top of the window sets how many contour levels are drawn; the "N contour levels" label beneath it shows the current count. The levels snap to "nice" round step sizes (for example 5, 10, 50, 100 …) so the colour key stays easy to read. With the slider focused, the left and right arrow keys step down or up to the next preferred set of levels.

The 3D Relief View

Choosing 3D in the display-mode drop-down draws the data as a shaded relief surface, lit from the north-west. Any places you have added appear as little flagpoles whose flags carry the place names, and the red N compass arrow points to the projected north.

Rotate the view by dragging on it with the mouse (or one finger): dragging left/right spins the view (its compass bearing) while dragging up/down tilts it between almost straight-down and nearly edge-on.

Two vertical sliders sit beside the view:

  • The Height slider on the right exaggerates or flattens the vertical scale, making subtle terrain easier to see; the flagpoles grow and shrink along with the relief.
  • The Grid slider on the upper-left sets the mesh granularity — higher gives a finer, more detailed surface (slower to draw), lower a coarser, faster one.

Zoom the 3D view by pinching with two fingers, or with the mouse wheel / trackpad. The terrain and its labels zoom together.

For smooth rotation the 3D surface is drawn on your graphics card (GPU) where a suitable one is available, falling back to the processor otherwise. A small marker in the lower-left corner of the map shows which is in use (for example GPU 3D: …, or CPU only).

Contour Colour Schemes

Tap (or click) the contour-levels key in the lower-left of the map to open the Contour colour scheme chooser. Each option shows a preview strip of the colours your current contour heights would have under that scheme. The schemes are:

  • Hue Ramp — HSL hue ramp, blue "sea level" then green through violet.
  • Greyscale — dark for low ground through to near-white for the highest, optionally with a gentle colour cast (see Hue below).
  • Hypsometric — the classic atlas terrain tints: green lowlands through yellow and tan to brown uplands and grey/white peaks.
  • Terrain + water — like hypsometric, but sea level and below are shown in blue (deeper = darker), which is handy for data that dips below zero.
  • Viridis — a perceptually-uniform, colour-blind-friendly ramp (purple-blue through teal and green to yellow), where equal colour steps mean equal elevation steps.

At the top of the chooser are sliders that fine-tune the scheme they belong to — each one is enabled only while its scheme is selected:

  • Hue start and Hue range — shift and widen the band of colours used by the Hue Ramp scheme.
  • Hue — shown in place of Hue start while Greyscale is selected. Fully left is plain grey; moving it right gives the greys a soft cast running from red through orange, yellow, green and blue to violet — a touch of red for Mars, for example. The strip under the slider shows the cast at each position, and the setting is remembered between sessions.
  • Shade mute — tones down (desaturates) the filled Hypsometric colours towards grey, so large shaded areas look less garish. Its setting is remembered between sessions.

The map updates live as you change the scheme, the sliders, or the switches below, so you can see the effect straight away. Reset puts the selected scheme's sliders back to their standard settings (for the Hue Ramp, the automatic colours chosen to suit your data), Cancel puts everything back to how it was when you opened the chooser, and OK keeps your changes. The chosen scheme applies to every display mode, including the 3D view, and is remembered between sessions.

The chooser also has a 3D block sides section with two switches for the 3D relief view:

  • Fill the data-block side walls — closes in the four vertical edges of the data so the relief looks like a solid block sitting on its lowest-elevation plane, rather than a floating sheet. The faces are shaded by the same light as the terrain.
  • Mystery Bonus Edge decoration — just for fun: draws those walls as a dark sandy rock face with the occasional dinosaur skeleton (a T-Rex, a long-necked sauropod, a plated stegosaurus, a horned triceratops — plus the odd bone, ammonite, fish or footprint) embedded in the strata. The fossils stay put in the rock as you rotate. On a map of another world, look closely: whatever is buried there, it is not dinosaurs.
    Both switches are remembered between sessions.

Adding and Editing Places

Click the highlighted button to show the Add or Edit a Place dialog. This lets you enter a place name, description, coordinates, and elevation for a new place, and add it to the list in the Show Places list dialog. If you double-click on a place in that list it will also invoke the Add or Edit a Place dialog. If the place does not have elevation data (shown as empty or −1000000) and it is within the currently loaded map data, the elevation field will be highlighted in purple with a suggested value filled in. Click Update Place / Add Place to save, or Cancel to exit without changes.

The Place Name field is also a search box: start typing and a drop-down list of matching places appears. Use the country selector beside it to narrow the search to a particular country. Choosing a place fills in its coordinates, sets the description to Place, County, Country, and fills in the elevation automatically. Place search is powered by GeoNames.

You can also right-click (or press and hold) anywhere on the map to see a list of the nearest places. Choosing one opens the Add or Edit a Place dialog ready-filled with that place's name, description and coordinates, together with its elevation where available. The most recently chosen place is remembered, so clicking the Add or Edit a Place button afterwards re-opens the dialog pre-filled with it.

Places on other worlds

Every place records which world it is on. The Planet/Body drop-down at the top of the Add or Edit a Place dialog shows it: for a new place it starts on the body of the map you have loaded, and for an existing place it shows that place's own body. A place only ever appears on maps of its own body, so a town on the Earth and a crater on the Moon can share a latitude and longitude without turning up on each other's maps.

GeoNames is a gazetteer of the Earth, so on another world the place-name search looks through KOContour's own built-in places for that world instead. With Planet/Body set to Mars, typing mar offers Valles Marineris; choosing it fills in the name, description and coordinates. A place you already have is marked (already in your places), so you don't add it twice. The Country selector is switched off for other worlds.

For anywhere not in the built-in list, type the name and description and paste in the coordinates yourself. The Apollo 11 landing site, for instance, is at 0.67416, 23.47314 on the Moon. As with any place, you can leave the elevation blank and have one suggested from the loaded map when you next open the place for editing.

On a map of another world, right-clicking offers Add a place here on Mars… (naming whichever world it is), which opens the dialog with the coordinates of the point you clicked and its elevation already filled in. Below it, nearest first, come your own places on the map (marked ★, to edit them) and up to ten of the built-in places for that world that are on screen and not yet among yours: choosing one of those opens the dialog with its name, description, coordinates and elevation filled in, ready to add. Longitudes are from −180 to 180 with east positive, as described in Maps of Other Worlds.

Example: the proposed Apollo 18 landing site

Apollo 18 never flew: it was cancelled, with Apollo 19, in September 1970. Its target changed during planning — Schröter's Valley and the crater Gassendi were both considered — but NASA's last plan before the cancellation, in March 1970, sent it to the Copernicus crater. No exact landing point was ever fixed, so this example uses the crater's official centre, which lies among its central peaks.

  1. Load the Copernicus map from the example above.
  2. Click the Add or Edit a Place button. Because a Moon map is loaded, Planet/Body is already set to Moon, the place-name search looks through the built-in Moon places, and the Country selector is switched off.
  3. Type Apollo 18 (proposed) as the Place Name and something like Proposed Apollo 18 landing site, Copernicus crater, Moon as the Description.
  4. Paste 9.62, -20.08 into Paste lat,lon here.
  5. Leave the Elevation blank, and click Add Place. The place appears on the Copernicus map, and as a flagpole in the 3D relief view.
  6. To fill in its elevation, open the place again (double-click it in the places list): KOContour suggests one from the loaded map, highlighted in purple. Click Update Place to keep it.

As a shortcut, right-click the middle of the crater on the map and choose Add a place here on Moon…: the dialog opens with the coordinates of the point you clicked and its elevation already filled in, so you only need to type the name and description. The place is saved as a place on the Moon, so it never appears on a map of the Earth, even one that covers the same latitude and longitude.

Places you saved with earlier versions of KOContour did not record a body; they are all treated as places on the Earth, which is what they were. The same goes for places files exported from earlier versions when you import them.

Example: adding Lahaina on the Earth

As an example, let's add Lahaina.

If you have not yet set up a free GeoNames account (and I would strongly recommend that you do) you can use Google Maps as described above to get the coordinates for Lahaina and paste them into the dialog, then add the other details If you have set up your GeoNames account, and entered the username then you can type the first few letters of the place name and a list of suggestions will pop up. Click on the one you you want, and it will populate all the fields in the dialog for you. This is the easiest way of getting the data.

With the coordinates filled in, give the location a name and a short description, and add an elevation if you know it — or leave the elevation blank and let KOContour suggest one from the loaded map data. As a shortcut you can type the place name straight into the Place Name search box and pick it from the drop-down list, which fills in the coordinates (and elevation) for you. When every field shows a valid (green) value, click Add Place to save it.

Lahaina will appear on the map and be highlighted as shown.

Try adding another place such as Paia. Leave the elevation unset and save the new place, then continue to the next section.

Showing the Places List

Click the highlighted button to show the Show Places list dialog. Places are maintained in alphabetical order. Double-clicking an entry launches the Add or Edit a Place dialog. If a place does not have elevation data and it is within the currently loaded map data, the elevation field will be highlighted in purple with a suggested value.

Try looking for Paia — you can jump to the P section by pressing the P key. Double-click on Paia; if the elevation was left as the default (−1000000 means undefined), it will suggest an elevation read from the map’s height data at that point and highlight it as shown. Places visible on the currently loaded map are shown in cyan, otherwise they are shown in light gray. The list holds your places on every world together; a place counts as on the map only if the map is of the same body, and the tooltip of a place on another world says which it is on. If you re-type in the place name it will suggest a more accurate elevation from GeoNames - 232.9 feet - if you have set up your account on that as described below.

Getting a GeoNames username. KOContour looks up place names — the places near where you right-click the map, and the suggestions as you type a place name — using GeoNames, a free online directory of places. GeoNames asks each person using it to have their own username. It is completely free, needs no payment card, takes about two minutes, and you only ever do it once:

  1. Sign up at https://www.geonames.org/login — just choose a username and a password, and give your email address.
  2. Open the email GeoNames sends you, and click the link in it to confirm your address.
  3. Switch on the free web services — this step is easy to miss. Sign in at GeoNames, go to https://www.geonames.org/manageaccount, and click the link near the bottom of the page that says it will enable your account for the free web services. Until you do, GeoNames says the account is “not enabled to use the free webservice”, even though the account itself is there.
  4. Back in KOContour, click the padlock button beside the place name in the Add Place dialog (or in the elevation data download dialog), type your GeoNames username — just the username, not your password — and click Save. If you right-click the map before you have done this, KOContour offers to take you straight there: choose Enter my username.
If place look-ups don’t work: testing your GeoNames account (technical)

You can check your GeoNames account directly by typing the following into the address bar of your web browser:

http://api.geonames.org/searchJSON?name_startsWith=<placename>&featureClass=P&maxRows=10&username=<username>

Replace <placename> with the start of a place name and <username> with your GeoNames username. If your account is working, this returns a list of matching places and the details of each. If it says the account is “not enabled to use the free webservice”, do step 3 above.

Click Update Place to save the place data and elevation, which will then appear on the map under the place name.

Finding the Elevation

To find the elevation of a point, click on the map at the desired location. A marker will appear showing the elevation along with the latitude and longitude. To remove it, click again in the centre of the crosshair.

Distances and Compass Bearing

To find the distance between two points, hold the Ctrl key and click on the map at the first location. A marker will appear. Keep holding Ctrl and click the second point. A line will be drawn between the points showing the distance and compass bearing. To remove the measurement tool, click again in the centre of either crosshair.

Distances are worked out over the surface of the world the map is of, so on a map of another world they use that body's size, not the Earth's. One degree of latitude is about 111 km on the Earth, 59 km on Mars, 43 km on Mercury and 30 km on the Moon.

Showing the Favourites List

Click the highlighted button to show the Show Favourites list dialog. The list is maintained in last-access order, most recent first. Double-click an entry to load that data file. If the file no longer exists you will be asked if you would like to remove it from the list.

Toolbar Option Checkboxes

The Light Theme checkbox switches to a light background, which is sometimes better for printing. The Load at startup checkbox causes the app to automatically load the last successfully loaded data file at launch, if it still exists. Both of these settings are persisted across launches. The Show places option is not persisted.

Everything else is easy to figure out from the tooltips and prompts — have fun exploring!

Features

Contour Display Modes

Draw the data as contour lines, a smooth gradient shade, solid block shading, or a 3D relief surface.

3D Relief View

GPU-accelerated 3D terrain you can rotate by dragging, with sliders for vertical exaggeration and mesh granularity, and pinch / mouse-wheel zoom.

Colour Schemes

Tap the contour key to choose a colour scheme: the original, greyscale, hypsometric terrain tints, terrain-with-water, or perceptually-uniform Viridis.

Adjustable Contour Levels

A slider sets the number of contour levels, snapping to round step sizes; arrow keys step through the preferred level sets.

Other Worlds

Choose the Moon, Mercury, Venus, Mars, Vesta, Ceres, Pluto or Charon in the download dialog to map craters, volcanoes and ice plains from NASA spacecraft data, with distances worked out for that world and your own places on it. No key needed.

DEM Server Integration

Fetch elevation data directly from Open Topo Data or OpenTopography servers, with automatic rate‑limit handling and progress reporting — or from USGS Astrogeology for the Moon and seven other worlds.

Elevation Grid Generation

Create a ready-to-use elevation TSV grid for any region from a lat/lon centre point, with the elevations filled in directly from the chosen DEM server.

Contour Map Rendering

Load TSV elevation files and generate detailed contour maps with zoom, pan, height scale, and distance scale overlays.

Places Management

Add, edit, and store named places with coordinates and elevation, including automatic elevation suggestions from map data.

Elevation Lookup

Click anywhere on the map to display the elevation and coordinates of that point.

Distance & Bearing Tool

Hold Ctrl and click two points to measure distance and compass bearing between them.

Favourites List

Automatically tracks recently loaded data files for quick reloading, with missing‑file cleanup.

Toolbar Options

Includes light theme mode, load‑at‑startup, and show‑places toggles, with persistent settings.

Place Search

Type a place name in the Create-GPX or Add-Place dialogs and pick from a drop-down of suggestions, optionally filtered by country, to fill in coordinates and elevation. Powered by GeoNames.

Nearby Places

Right-click anywhere on the map to list the nearest places and add any of them to your places with a single click.

Drag-to-Zoom

Click and drag a proportional selection box across the map to zoom into an area; press Esc to cancel.

Place Import and Export

You can import and export your saved places from the Places List dialog. It will warn if there are duplicates. Each place carries the world it is on; files from earlier versions import as places on the Earth.
